Convolutions from Scratch

Let's start by implementing a convolution. I implemented a function that takes a filter and applies it to every pixel in an image, with options for using 4 or 2 for loops. 

def convolve(image, filter, num_loops=2):
  image_height, image_width = image.shape
  filter_height, filter_width = filter.shape
  padding_height, padding_width = filter_height // 2, filter_width // 2

  padded_image = np.zeros(
    (image_height + 2 * padding_height, image_width + 2 * padding_width)
  )
  padded_image[
    padding_height : padding_height + image_height,
    padding_width : padding_width + image_width,
  ] = image

  convolved_image = np.zeros(image.shape)
  if num_loops == 2:
    for k, filter_row in enumerate(filter):
      for l, filter_px in enumerate(filter_row):
        centered_k, centered_l = k - padding_height, l - padding_width
        convolved_image += (
          padded_image[
            padding_height - centered_k : (padding_height + image_height)
            - centered_k,
            padding_width - centered_l : (padding_width + image_width)
            - centered_l,
          ]
          * filter_px
        )
  elif num_loops == 4:
    for i in range(image_height):
      for j in range(image_width):
        for k, filter_row in enumerate(filter):
          for l, filter_px in enumerate(filter_row):
            centered_k, centered_l = k - padding_height, l - padding_width
            convolved_image[i][j] += (
              padded_image[
                (i + padding_height) - centered_k,
                (j + padding_width) - centered_l,
              ]
              * filter_px
            )
  else:
    raise ValueError
  return convolved_image

In the version with 4 loops, for every pixel in the image, we iterate through each pixel in the filter and apply it to the image. This works but is quite slow, so the 2 loop version instead uses vectorization to apply each pixel in the filter to the whole image at once, which sped things up by 3 to 4 times in my experience.

One might ask what happens with pixels at the boundaries of the image. To avoid the filter going out of bounds for these pixels, we pad the image with zeros, equal to half the height/width of the filter on each side.

Image Sharpening

Let's implement an unsharp mask filter that sharpens an image. Taking the Gaussian of an image isolates lower-frequency components, so if we subtract the Gaussian from the original image, we can isolate the higher-frequency components of the image, also known as the Laplacian. We can then add this Laplacian, multiplied by an alpha factor, back to the original image to sharpen it.

For our sharpening purposes, we'll use an alpha factor of 2. The results of sharpening several images are shown below.

Increasing the alpha factor increases the degree of sharpening, as seen below using an alpha factor of 10.

What happens if we try to re-sharpen a blurred image? The result is shown below. Since blurring gets rid of high-frequency information, sharpening only amplifies the remaining high-frequency information and cannot recover information that was lost in the blur. As a result, the image is sharpened but still lacks the fine detail of the pre-blurred image.

Multiresolution Blending

For our finale, we're going to implement multiresolution blending for a smooth transition between two images using Gaussian and Laplacian stacks! Let's first take a look at blending an apple and an orange: an "oraple," so to speak.

For each level of the Gaussian and Laplacian stack, we blur the Gaussian and subtract that result from the Gaussian to get the Laplacian. This allows us to reconstruct the original image by adding the Laplacians back to the Gaussians of the previous level. We'll be using 7 stack levels for this instance.

Additionally, we'll apply a mask on the two images to isolate the left half of the apple and the right half of the orange in each level. As we go down the stacks, we'll blur the mask so that low-frequency components of the images are blended together smoothly while high-frequency patterns are preserved. This allows for a seamless transition between the two images. The results of this blending process are shown below (The first three rows represent Laplacian levels 0, 2, and 4).
