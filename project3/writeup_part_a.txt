To perform one-step denoising using a pre-trained model, I implemented `one_step_denoise` below and then used it to denoise my noisy images (top to bottom is t = 0.25, 0.5, 0.75):
```
def one_step_denoise(x, t, condition, predict_velocity):
    return x + (1 - t) * predict_velocity(x, t, condition)
```

Instead of performing denoising in one step, we can also do iterative denoising with Euler sampling. I implemented `euler_sample` below and used this to perform 25 Euler updates on my t = 0.50 noisy image. You can see the results after every fifth update below.
```
@torch.inference_mode()
def euler_sample(x_start, t_start, step_size, velocity):
    x, t = x_start, t_start
    states = [(t, x)]
    while t < 1:
        h = min(step_size, 1 - t)
        x = x + h * velocity(x, t)
        t += h
        states.append((t, x))
    return x, states
```

We can also use classifier-free guidance to strengthen the effect of the prompt and give us higher-quality results. I implemented the `cfg_velocity` function as follows and used that to generate 5 CFG samples with "a high quality photo," using the same initial noises below:
```
def cfg_velocity(x, t, condition, w, predict_velocity, null_condition=''):
    v_c = predict_velocity(x, t, condition)
    v_u = predict_velocity(x, t, null_condition)
    return v_c + w * (v_c - v_u)
```

We can create optical illusions using flow models, as well.

At a timestep, we can predict the velocity with one prompt and another velocity with the flipped image and a second prompt. We can then reverse that second velocity and take the average of the first and second prompt velocities to get our overall velocity. Following that approach, I implemented `visual_anagrams` below:
```
def visual_anagrams(noise, condition_a, condition_b, predict_velocity, w=7, step_size=0.02):
    def velocity(x, t):
        v1 = guided(x, t, condition_a, w)
        v2 = rotate180(guided(rotate180(x), t, condition_b, w))
        return (v1 + v2) / 2

    return euler_sample(noise, 0, step_size, velocity)[0]
```

What if we wanted a hybrid image? We can create a composite velocity by predicting velocities for two separate prompts, then combining the low-pass of one with the high-pass of the other. That's the approach I take with the following `make_hybrids` function:
def make_hybrids(noise, condition_a, condition_b, predict_velocity, w=7, step_size=0.02):
    def velocity(x, t):
        v1 = guided(x, t, condition_a, w)
        v2 = guided(x, t, condition_b, w)
        return lowpass(v1) + (v2 - lowpass(v2))

    return euler_sample(noise, 0, step_size, velocity)[0]
